# TOP_Rock-Paper-Sciscors
TOP game project

Pseudocode

1. Set Rules Rock > Paper > Scissors, Scissors > Rock
2. Get character of the player (Rock, Paper, Scissors)
3. pair it with a random character (Rock, Paper, Scissors)
4. based on the rule compare the player character with the randomized character
5. evaluate which one is higher
6. print the character winner
